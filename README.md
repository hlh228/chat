# 轻量聊天室

原生 HTML/CSS/JavaScript + FastAPI + SQLite 实现的即时通讯 Web 应用，
全站零构建、零前端框架，后端 5 个接口 + 2 秒轮询收发消息。

## 启动
1. 双击 `backend\启动后端.bat`
2. 浏览器打开 http://127.0.0.1:8000/

## 测试
在 `backend` 目录下运行 `测试聊天功能.py`，会自动用临时数据库跑完整套接口检查。

## 已实现功能
- 注册 / 登录
- 一对一聊天、查看历史消息、2 秒准实时收消息
- 断线自动重连（退避重试）+ 顶部连接状态提示
- 手机端自适应布局（375px 可用）
- 后端顺带托管前端文件，只开后端即可
- 会话查重

## 未实现功能
